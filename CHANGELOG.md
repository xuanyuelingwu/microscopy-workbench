# Changelog

## 1.0.0 — 2026-10-20

Initial public community release of the processing core prepared during the NucleArk microscopy project.

- Native ND2 and calibrated single-series OME-TIFF input.
- Native-position 3D inspection and marching-cubes isosurfaces, with acquired-slice and same-position overlap checks.
- Full-field and fixed-ROI GIF/MP4 export with independent interval/time-zero controls and recorded frame maps.
- Source hashes, processing parameters, environment/code fingerprints and replay commands.
- Two explicitly synthetic OME-TIFF examples with independent expected values and portable numerical/export tests.
- English and Chinese documentation, MIT license, dependency notices and package/CI checks.

The public packaging and documentation build on the locally validated 2026-10-19 source snapshot. No additional biological validation or external adoption is asserted by this release.
