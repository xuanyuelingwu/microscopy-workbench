显微图像工作台 1.0
本地交互式三维重构与时间序列视频

使用
在当前项目机器上双击 start.bat。脚本会使用现有的科研 Python 环境并打开浏览器。
请保留服务窗口运行。关闭服务窗口后，页面不能继续计算；重新启动即可重新选择文件。
该工具由 HTML 界面与本地 Python 计算服务组成，不需要上传到互联网。
在另一台 Windows 机器上，先安装 Python 3.12，运行 install.bat 安装独立环境，然后运行 start.bat。
也可手动执行 python -m pip install -r requirements.txt；python app.py。
全部依赖安装完成后即可离线使用。支持 Chrome、Edge 等具备 WebGL 的现代浏览器。

输入
ND2 为原生逐采集帧读取，不一次载入整个时间序列。
支持单 series、灰度通道、轴定义明确的 OME-TIFF。
普通 TIFF 的 Q / I / S 轴不会被猜测为 Z 或 T；RGB 相机 ND2 暂不支持。
时间序列至少需要两帧 T，三维重构至少需要两层 Z。可明确固定其他采集维度，例如位置、时间或 Z。
“选择文件”会将源文件复制到 workspace/uploads。大文件可用“本机路径”直接读取，避免复制。
请等文件下载完成再打开；源文件改变后工具会要求重新载入。

时间序列到视频
选入文件后先生成完整时间段全视野预览。初始显示范围参考首帧，可手动更改。
用原生帧滑块或播放器定位；在任意帧画框，或输入原像素 x、y、宽、高。
“移动 / 缩放”模式可拖动框内移动、拖动四角调整大小。ROI 固定用于整个片段，不自动追踪或漂移校正。
拖动时间轴端点或输入起止帧，终止帧包含在内。时间零点可选任意原生帧，也可输入采集时间。
零点和 ROI 参考帧均可在导出区间之外。输出保留完整时间精度的映射 CSV。
点击导出，同时生成该区间全视野与局部的 GIF、MP4。整片固定 LUT 和 gamma，不逐帧自动归一化。
保留全部原始帧；MP4 用重复帧表达不等间隔时间，GIF 按 10 ms 量化。过高倍速自动降低，实际倍速写入参数。
最终原生帧的停留时间取所选相邻间隔中位数，并明确记录。GIF 播放器可能限制短帧时间。
文字和比例尺在独立黑色页脚；奇数图像尺寸仅补黑边。仅显式指定输出最长边时才缩小，绝不伪造更高分辨率。

两种三维重构
方法一为真实采样位置点，使用文件记录的物理 Z 坐标；不可用时，仅按已校准的名义间距备选并记录。
每个显示点来自真实合格像素；每 XY 区块与显示点上限可以简化显示，但统计始终使用全部原生像素。
方法二为 Marching cubes 强度等值面，相邻采样位置间线性定位表面，保留真实物理比例。
默认表面步长 1，不做 XY 平均、平滑、去卷积或超分辨率。更大步长属于明确选择的显示简化。
可分别调整通道颜色、阈值和不透明度；结果页提供原生位置 / 等值面切换、旋转、缩放和原生切片核查。
金色点来自同一实测 XYZ 双通道同时超阈值，不将不同 Z 的投影交叠当作共现。
三维定量给出两通道各自的重叠积分比例及合并比例。积分为 max(I-background,0) 在超阈值像素上求和，
乘 XY 像素面积后跨实测层相加；不是连续空间体积积分。合并值受染料、激光和增益的通道权重影响。
默认 150 a.u. 只是可编辑起点，不能作为所有采集条件通用的背景门限。请结合原生切片与敏感性判断阈值。
共现不证明分子结合，插值表面不增加采集分辨率。

输出与复现
每次任务写入 workspace/outputs/时间戳_随机ID，避免覆盖旧结果。
settings.json：通道、LUT、背景与阈值、采集维度、裁剪范围、参考帧、时间零点、坐标、编码和有效倍速。
source.json：源文件名、机器上的原路径、SHA-256、原始维度、校准及关键元数据。
software_versions.json：解释器、库、FFmpeg 版本以及处理代码 SHA-256。
manifest.json：逐文件大小与 SHA-256。bundle.zip 为该次完整结果；原始 ND2 不包含在 ZIP 中。
三维另含原始 OME-TIFF / NPZ、实测 Z CSV、native_overlap.csv、原生掩膜、原生切片和 PLY。
视频另含逐原生帧时间表、各通道时间、饱和 / 显示裁剪统计、无标注参考 PNG 与 ROI 来源图。
复现命令：
python replay.py --source "原始文件.nd2" --settings "结果目录/settings.json" --output "新目录"
默认要求源文件 SHA-256 一致。对另一个文件应用同一协议须明确加 --allow-different-source。
数值定义、帧映射、ROI 与 LUT 可复算；不同系统的有损编码文件不保证二进制一致。

示例与核验
examples/ 中有两个明确标记 SYNTHETIC 的 OME-TIFF，不是实验数据，不应出现在生物学结果中。
一个示例有不等间距 Z，另一个有不等间隔时间；有预置配置和独立参考数值。
python -m unittest discover -s tests -p "test_*.py" -v
tests/test_core.py 核对积分、阈值等号边界、真实点坐标、非均匀 Z 表面、时间量化、奇数 ROI 和 TIFF 轴。
项目内另以三个真实 ND2 数据集检验原生读入、数据备份、表面与时间导出，并实际测试浏览器交互。
validation/VALIDATION_SUMMARY.json 保存交付时通过的检查及其范围。尚不宣称已有外部社区使用或跨实验室验证。
