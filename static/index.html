结果与复现文件

启动与数据保留

双击工具目录中的 start.bat，保留服务窗口运行。所有计算只在本机进行。浏览器不直接解析 ND2，而是连接本地 Python 服务。

“选择文件”会复制到本地 workspace/uploads；大文件可粘贴完整路径直接读取。处理结果保存在 workspace/outputs 的独立时间戳目录中。新机器先安装 Python 3.12，再运行 install.bat。

时间序列

  1. 选择时间序列文件，检查固定位置、固定 Z 层以及显示通道。工具自动生成完整时间段的全视野预览。
  2. 使用原生帧滑块，或在视频中定位后点击“将视频当前位置载入”。在任意帧上画框；在移动模式拖动框内移动、拖动四角调整大小。
  3. 拖动时间轴端点或输入起止帧。计时零点可设为任意原生帧，也可输入采集时间；它独立于片段起点。
  4. 点击导出，同时获得全视野与局部的 GIF、MP4、无标注参考图、ROI 坐标、逐帧时间表、固定 LUT 和复现配置。

所有源帧均保留。MP4 以重复帧近似不等间隔的采集时间；GIF 使用 10 ms 时间单位，实际播放还取决于播放器。末帧停留时间取所选相邻间隔中位数。时间不是人工插值后的“新观测”。

三维

  1. 选择含 Z 维度的文件，并明确固定时间与位置。核对 XY 像素尺寸与 Z 坐标来源。
  2. 选用一或两个通道，设置背景和“背景以上阈值”。显示上下限 / gamma 只影响二维切片与视频；三维的入选位置由背景和阈值决定。
  3. 点击生成两种视图。在结果页切换原生位置与插值等值面，分别调整通道透明度；金色点是两个通道在同一实测 XYZ 同时超阈值的位置。

原生点为真实采样坐标，显示可有抽样；统计使用全部原生像素。Marching cubes 等值面只在相邻采样位置间线性定位表面，不能增加显微镜的空间分辨率。共现不是分子结合的证明。

可复现输出

每个结果包包含源文件 SHA-256、settings.json、software_versions.json、METHODS.txt 和逐文件校验清单。三维另含原始 OME-TIFF / NPZ、Z 坐标 CSV、原生阈值共现 CSV 与 PLY 表面。原始文件不包含在下载 ZIP 内。

python replay.py --source "原始文件.nd2" --settings "结果目录/settings.json" --output "新的输出目录"

默认必须匹配原始文件 SHA-256；把相同协议应用到另一文件需要显式指定 --allow-different-source。复现重算数值与源帧映射，编码文件不保证跨平台二进制完全一致。

明确的处理边界

不做人工补画、去卷积、超分辨率、自动漂移校正、Z 最大投影冒充单层、或逐帧自动归一化。叠加颜色不用于定量。缺少真实物理校准或时间记录时，工具提示填写已知参数，不猜测单位。

支持单个灰度荧光 ND2 和单 series、轴定义明确的 OME-TIFF。经典 TIFF 的 Q / I / S 维度不会被自动当作 Z / T；RGB 相机 ND2 暂不支持。单次三维体数据暂设 1.6 GB 内存上限，必要时先框选局部。
